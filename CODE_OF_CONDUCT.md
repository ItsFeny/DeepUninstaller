# Código de Conducta

Este proyecto adopta el [Contributor Covenant, versión 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

En resumen: sé respetuoso, acoge a personas de todos los orígenes y niveles de experiencia, acepta la crítica constructiva y céntrate en lo que es mejor para la comunidad. No se tolera el acoso ni el lenguaje ofensivo.

Para reportar un comportamiento inaceptable, contacta a la persona mantenedora en fenymartinez459@gmail.com.
